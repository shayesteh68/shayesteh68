# Narges Shayesteh

**Bioinformatics Analyst | MSc Biophysics | RNA-seq & single-cell transcriptomics**

I build and review reproducible R/Python workflows for public and client-authorized transcriptomics data. My portfolio focuses on count-matrix and metadata checks, bulk RNA-seq reanalysis, single-cell QC and marker review, donor- or pool-level pseudobulk, and clear technical reporting.

## Selected projects

- [LOY bladder-cancer reanalysis](https://github.com/shayesteh68/LOY-BladderCancer-ImmuneEvasion-GSE290114) — DESeq2 comparison of MB49 Y-chromosome knockout and control, with exploratory pathway analysis.
- [Paired ccRCC RNA-seq](https://github.com/shayesteh68/ccRCC_GSE278174_salami) — reanalysis of 19 paired patients using a provenance-checked sample map.
- [Harmony integration example](https://github.com/shayesteh68/scRNAseq_Harmony_Integration) — Seurat/Harmony integration demonstration; treatment-effect analysis uses raw-count donor-paired pseudobulk.
- [Barrington snRNA-seq](https://github.com/shayesteh68/barrington-snrna-sex-dimorphism) — pool-level pseudobulk with marker-supported provisional cell annotations.
- [Drosophila Stage 6 scRNA-seq](https://github.com/shayesteh68/Drosophila_scRNA_Stage6) — Seurat v5 QC, clustering, and marker review.
- [PBMC3K Seurat workflow](https://github.com/shayesteh68/scrnaseq-seurat-pbmc3k) — single-sample example with QC, clustering, and provisional labels.

## Services

- RNA-seq count-matrix and sample-sheet quality checks
- R/Python workflow review and small-scope debugging
- Reproducibility checks and concise technical reports
